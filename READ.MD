# SafeCity AI

SafeCity AI is a women’s safety web application designed to make everyday travel feel a little safer. The idea behind this project was to create something practical that combines emergency features with location-based safety information in one simple platform.

I built this project to explore how technology can help solve real-world safety problems while improving my full-stack development skills.

## What it can do

- Emergency SOS button with a countdown before activation
- Live location sharing using the browser’s GPS
- Interactive safety map with high and low-risk zones
- AI-inspired safety score based on location data
- Incident reporting interface for users
- Responsive and easy-to-use design

## Why I built it

The goal wasn't just to build another web app—it was to work on a project that feels relevant to everyday life. SafeCity AI helped me practice building an interactive frontend, connecting it with a Flask backend, working with maps through Leaflet, and designing features that focus on user safety.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/Women-Safety-AI.git
cd Women-Safety-AI
```

### 2. Install backend dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 3. Start the Flask server

```bash
python app.py
```

### 4. Open the frontend

Open `frontend/index.html` in your browser, or run it using VS Code Live Server for the best experience.
